About App Lock

App Lock is an Android security application designed to help users protect selected applications and personal content with an additional layer of security.

The application is designed with simplicity, privacy and security in mind, allowing users to control which applications require additional authentication.

Features

🔐 App Protection

Protect selected Android applications with an additional authentication layer.

🔑 OTP Verification

Optional OTP emails can be used for security verification.

⚠️ Security Alerts

Receive security notifications about relevant authentication events.

🛡️ Privacy Focused

The application requests only the permissions necessary for its enabled features.

Google Account & Gmail Integration

App Lock provides an optional Google Account connection for users who want to receive security-related emails.

When Gmail integration is enabled, App Lock uses Google's Gmail API with the gmail.send permission.

This permission is used to send emails on the user's behalf, such as OTP messages and security notifications.

App Lock does not use this Gmail permission to read, search, modify or delete the user's existing Gmail messages.

Privacy & Security

We respect your privacy. App Lock is designed to minimize access to personal information and use permissions only for the features that require them.

App Lock does not request or store your Google Account password.

For complete information about data handling, Google integration and your choices, please read our Privacy Policy.
